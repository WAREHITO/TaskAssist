# 仕事アシスト（TaskAssist）

Windows向けの、個人用タスク・カレンダー・回答管理アプリです。覚えておくことを減らし、案件の受付から回答確認までを記録するために作っています。

このリポジトリは **0.4.0 ローカル版のソース** です。初回起動時は空の記録で始まります。実メールとの接続はありません。試験用の架空データは製品の実行フォルダーに同梱しません。

## できること

- 用件名だけで登録し、期限・メモ・次の一手を後から補う。
- 作業中・保留・返答待ち・完了などの状態と変更履歴を残す。
- 受付日から回答期限までを、月をまたぐカレンダーの色付き帯で見る。
- 担当ごとに「未依頼 → 依頼済み → 回答あり → 確認済み」をクリックで更新する。依頼日、回答日、回答内容、補足を保存する。
- 所属名と担当一覧を自分で設定する。異動時は新しい所属を空の状態で始め、旧所属の案件・回答・判断・履歴を閲覧用に残す。
- 文字サイズを変更する。ローカルにバックアップを作り、同じWindows利用者の環境で復元する。

## 動作・開発環境

Windows 11 x64、C# / WPF / SQLite / .NET 10 を使用しています。確認に使ったSDKは **10.0.401** です。開発には [.NET SDK](https://dotnet.microsoft.com/download/dotnet/10.0) と PowerShell が必要です。Visual Studio Codeなどのエディターを使えます。管理者権限、Visual Studio本体、WSLは必須ではありません。

ソースを展開したフォルダーで、PowerShellから次を実行します。初回の依存パッケージ取得にはインターネット接続が必要です。

```powershell
./tools/build.ps1 -Publish
```

SDKを個別フォルダーに置いた場合は `-DotnetPath` で `dotnet.exe` を指定します。スクリプトはSDKの自動導入や実行ポリシーの変更を行いません。

成功すると、画面に試験結果のJSONと `.artifacts/publish/` 内の `TaskAssist.exe` の場所が表示されます。起動すると通常のアプリ用保存領域を使うため、開発中の画面確認には [架空データの試験用画面](docs/BUILD.md) を使ってください。

詳しくは [ビルド・試験](docs/BUILD.md)、[使い方](docs/USER_GUIDE.md)、[現在の仕様](SPEC.md)、[検証範囲](docs/QUALITY_GATES.md) を参照してください。

## 保存と現在の制限

記録はWindowsのローカルアプリデータ領域 `TaskAssist/Live` に保存します。DPAPIで保存内容を保護していますが、SQLiteファイル全体の暗号化ではありません。別PC・別Windowsアカウントへの移行機能はありません。所属の切替は、同じPC上で記録を分離する機能です。

実Outlook接続、実メールの読取り・送信、添付の解析、クラウド同期、複数人での同時利用、自動更新は未実装です。全仕様の完成版や、別PCでの動作確認済みの製品とはしていません。
