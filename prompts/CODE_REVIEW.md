# 分離したコードレビュー

実装者の意図を追認せず、`AGENTS.md`、`SPEC.md`、`docs/QUALITY_GATES.md` と実際の差分を確認する。最初は修正をせず、再現と根拠の確認を行う。

重点は、記録欠落、期限の誤変更、古い変更による上書き、保存の原子性、異動時の設定・記録の混在、入力を実行指示として扱う欠陥、ログ・公開物への私的データ混入。パッケージやAPIの不明点は公式情報で確認し、推測を事実扱いしない。

指摘ごとに重要度、ファイル・行、発生条件、影響、再現方法または根拠、修正方針、必要な再試験を記録する。修正は報告後の別工程とし、修正後の再試験を確認する。実行不能な試験は未実行とする。

指摘なしでも、対象版・確認範囲・環境・未確認事項・実装担当との関係を明記する。同じモデルの別コンテキストのレビューを、人間の独立監査とは呼ばない。私的な実パスを含む詳細な報告は公開対象外に保存する。
