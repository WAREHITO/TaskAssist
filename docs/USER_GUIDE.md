# 使い方

## はじめる

起動時に所属の表示名を入力する。局・課・担当など、自分が分かる名前でよい。初回は空の状態で始まる。「設定・診断」で担当一覧を登録すると、案件への担当追加が楽になる。

用件名を入力して登録し、必要になったら期限・メモ・次の一手を補う。期限が分からないときは「不明」のままにする。「期限なし」は期限がないと確認できたときに使う。

## カレンダーで案件を追う

カレンダーで案件の受付日と回答期限、色を設定する。期間は月をまたいでも確認できる。担当を追加し、依頼を出したら依頼済み、回答が来たら回答あり、内容を確認したら確認済みに進める。定型の回答を選び、必要な内容や補足を保存する。

この操作で実メールは送信されない。実際の依頼・回答連絡は普段使っている連絡手段で行い、アプリにはその状況を記録する。

## 人事異動のとき

同じ所属の名前を直すだけなら「所属の表示名を直す」を使う。記録を分けて新しい所属を始めるときは「異動・新しい所属を始める」を使う。

未完了案件ごとに、継続対応・引継ぎ・取りやめの判断と補足を記録する。新しい所属は空で始まり、旧所属は閲覧専用になる。継続する案件も自動では移らないので、新しい所属で必要な範囲を登録する。担当一覧は新しく設定し、文字サイズは引き継ぐ。

この操作はPC交換やWindowsアカウント変更の移行には使えない。

## 記録を守る

アプリのバックアップ操作で退避する。復元機能の対象は同じWindows利用者・同じ所属の記録。暗号化されたファイルをコピーするだけで別のPCで開けるとは限らない。

保存に失敗したときは表示されたエラーを確認し、記録を削除してやり直さない。問題を報告するときは、実際の案件名・回答・所属名を架空の内容に置き換える。
