# 1.0.0-rc.2 — 接続検証版

rc.2では濃紺と水色の専用アイコンを追加しました。実行ファイルとウィンドウに16〜256 pxの7サイズを組み込んでいます。業務機能と保存形式はrc.1と同じです。

カレンダー・担当別回答管理に、クラシックOutlookからの受付、定型規則、繰り返し業務、本人向け通知、添付保存、日次退避と復旧を追加しました。通常起動は空の本番用保存領域を使い、架空データを自動投入しません。既存利用者の記録は保持します。

実メール全経路と利用者受入は未確認です。当初要件すべてを合格とした完成版ではありません。実装と試験の範囲は [対応表](IMPLEMENTATION_STATUS.md) を参照してください。

## 起動・更新

Windows 11 x64用です。ZIP全体を新しいフォルダーへ展開して、その中の `TaskAssist.exe` を起動します。`outlook-worker` などの同梱ファイルも必要です。SDKの追加インストールは不要です。旧版のフォルダーを削除せず保持してください。

初期状態ではOutlook読取り・送信は無効です。[Outlook設定](OUTLOOK.md) に従い、起動済みクラシックOutlookの対象フォルダーと開始日時を本人が確認して設定します。本人通知・添付保存・下書きはそれぞれ別の承認です。

新しい版が形式3の記録を開く際、更新前の記録を退避して形式4へ更新します。旧版へ戻る必要がある場合は、設定の「選んだ更新前退避で旧版0.4へ戻す準備」を使い、アプリ終了後に保持した旧版を開いてください。更新後の記録は別に保持されますが、旧版の表示には含まれません。

## 確認済みと未確認

ローカルWindows上で架空データの自動試験と別コンテキストのAIレビューを実施しています。クラシックOutlookの実機確認はバージョン取得だけです。実メール読取り・原本不変・送信・添付保存・下書き作成、別PCや組織の制限環境は未確認です。自動試験やビルドの成功から、それらの合格を推定しません。

実行ファイルは未署名です。端末の安全設定を解除せず、組織のルールに従ってください。業務データ、個人のメールアドレス、認証情報を配布物へ含めない構成です。ライセンスは引き続き未指定で、第三者ライブラリの表示は `licenses` に同梱します。

ZIP横の `.sha256` はZIP全体、展開後の `SHA256SUMS.txt` は同梱ファイルの照合用です。SHA-256は電子署名を代替しません。
